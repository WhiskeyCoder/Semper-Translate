# Starter Lexicon — Marine ↔ English Reference

> **Note:** This file is a **reference glossary** (mostly Marine → English). The app uses reverse mappings in `data/*.json` (`authentic`, `barracks`, `meme_corps`).  
> **Ambiguity:** *Head* means bathroom (naval) **or** head/skull (*grape*) depending on context — the translator uses phrase context where possible.
